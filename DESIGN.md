# Frontier Harness dashboard

The owner-pinned Carbon/Nunito system carries this local operating interface.
Execution, questions and reviews are separate, readable work areas. Actual saved
work supplies all status and spending values. Fixture environments are explicit.

## Tokens

- Ground: `#0d0f12`; panel: `#1c1f24`; raised controls: `#252a33`.
- Text: `#f1f3f8`; secondary text: `#b6becd`; dividers: `#363d49`.
- Action/focus: `#a0b7ff`; selected surface: `#273652`.
- Success: `#a5d9c9`; attention: `#eac59b`; error: `#ffb5b8`.
- Self-hosted Nunito, 15px body/1.55 line height, 21px section headings, 26–36px
  outcome heading. Monospace is reserved for exact evidence and configuration.
- Panels use14px radii,24px padding and20px separation; controls use9px radii.

## Behavior

The desktop workspace uses an execution column and a review/question column.
Below800px these become one column; the main navigation wraps to its own row.
Goal preparation expands inline and displays the exact normalized approval hash.
Evidence, scope and priority controls expand inline. Typed answers are preserved
while background refresh is deferred. Focus rings are visible; optional attention
motion is disabled under `prefers-reduced-motion`.

Dynamic source/model text uses DOM text nodes. Controls call the same authenticated
API as MCP. A rendered state is never treated as authorization or a completed test.

Nunito's SIL Open Font License is shipped beside the font in the dashboard assets.
