# Codex only

Use the same installed `frontier-harness` MCP service. Read shared
[operations](../frontier-harness/references/operations.md) and, for coding,
[collaboration's native candidate lifecycle](../frontier-harness/references/collaboration.md).
Prepare/activate exactly authorized mode `codex_only` with native actor tasks.

Main Codex/native agents do implementation. Discover `native_start` supporting
`layout:"candidate_v1"` before launch, inspect its completed operation and use
only the returned candidate checkout. Follow the same finish, evidence review,
focused same-task revision and checked integration lifecycle. Inherit available
host capacity within approved limits; optional reviewer runs do not cap native
implementers. Read [native roles](../frontier-harness/references/native-roles.md)
before selecting role defaults or explicit supported model overrides.

Native consult/learning uses `native_text_start`/`native_text_finish`. For
public-source research use `research_start` and bounded `research_action`
search/read/finish with saved source IDs, exact passages and checksummed
collection. The deterministic path sends no DeepSeek request and performs no
DeepSeek self-check; label that honestly. Technical claims need primary sources.
Research collection/provenance is not independent factual certification.

This mode forbids DeepSeek planner calls, task dispatch, model-assisted research,
learning inference or fallback. Do not forge actor/role/model fields, call the
provider directly, use historical DeepSeek CLIs, or switch modes to bypass it.
If native capability/model/tools are unavailable, preserve state and report the
blocker. A registration reports model identity; it does not configure a provider.

Use saved IDs/mutation keys and bounded event waits. Verify actual host writer
quiescence before release or takeover; progress reports do not prove it. Main
review/integration requires an active chat, with no automatic native wakeup or
always-on supervisor. Finalize accepted integrated evidence or explicitly partial
quiescent work; report unavailable native usage as unknown.
