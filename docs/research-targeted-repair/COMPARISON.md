The saved comparison uses the actual archived A packet and its genuine submitted
revise findings, and the actual saved B catalog and recorded final verdict. Its
qualified patch and all other unit edits/checks are explicitly scripted fixtures,
not a new official report or semantic approval. Hash-bound comparison details are
retained in the private offline run's saved-comparison.json and saved-plan.json.

Meaningful RED→GREEN evidence covers absent targeted action support, policy opt-in,
worker lifecycle, Node v2 proof verification, duplicate JSON fields and SIGKILL
immediately after staged/terminal commits. Test setup/import/dependency failures
are retained separately and are not counted as behavioral RED evidence.

Source suites include named-unit/closed-shape/summary/selector/Unicode/mixed-catalog
checks, exact bundle/wire bounds, partial short circuit, stale and tampered state,
expiry/pause/spending, actual process kills, and whole B acceptance/rejection.
Existing @1–5 approval hashes, schemas and reserved payload fixtures remain intact.

The standalone CLI/SDK fixture executes the frozen runtime with development imports
denied, scripts a real Store/Worker A→revise→repair→B lifecycle, independently
records local review acceptance, collects the fixed artifact list, revalidates
query-only local authority and rejects altered proof/receipt data. It is not an
actual native CLI model host, live model run, personal installation or phone test.
